**Decided:** `AGENT.md` is tracked and read first every session: how to keep it, what metaSolid is,
its invariants, the principles shared with Hermetica and Iris (including how the agent
communicates: suggest by default, act end to end only when told, report faithfully) and the
conventions (ponytail, the nix shell, four environments, fixtures, the decision log). Added here:
functional first, with no classes; a configured behaviour is a closure.
**Why:** One instruction file per repo, versioned with the code, so a rule and its change are
reviewed like code. No CLAUDE.md, matching Hermetica and Iris.
**Cost:** Claude Code loads CLAUDE.md on its own, not AGENT.md; a session has to be pointed at it.
